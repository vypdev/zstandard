# zstandard_android legacy example

This example intentionally uses the last Flutter-supported pre-AGP-9
compatibility line: AGP 8.11.1, Gradle 8.14, and Kotlin Gradle Plugin 2.2.20.
The regular `example/` project exercises AGP 9.1.0 and built-in Kotlin.

Both examples consume the same `zstandard_android` plugin and are covered by
the Android CI emulator and native instrumentation tests.

Demonstrates how to use the zstandard_android plugin.
